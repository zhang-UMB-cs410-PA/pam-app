# PAM

A simple memory companion that runs in the terminal. Tell PAM things to remember, ask it to help you recall them, and get reminders.

## Run

```
npm install
export OPENAI_API_KEY=your-key
npm start
```

## Use

- Chat normally to save or ask about memories.
- `/memories` shows what is saved.
- `/quit` exits.

Memories are stored in `memories.json`.
